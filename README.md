# Ambition Skill

通过 Altitude（高度）、Depth（深度）、Range（广度）三个维度审视和提升任务、规划与交付物。

## 内容

- `SKILL.md`：保留原始 skill 内容，未改写。
- 本仓库只包含 skill 与说明，不包含具体项目代码、数据或评审结果。

## 使用

让支持本地 skills 的 AI 助手读取 `SKILL.md`，再提出需要审视的任务或规划，例如：

> 使用 ambition 审视当前规划与代码；区分已实现能力、证据缺口和探索方向，为每条建议指定外部验收依据。

在 Codex 中可将本目录放入 `~/.codex/skills/ambition/`；在 GitHub Copilot 中可放入 `~/.copilot/skills/ambition/`。安装后由对应客户端发现技能。
